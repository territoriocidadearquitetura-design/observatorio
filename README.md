# Plataforma OCIS

Site da Plataforma OCIS, Observatório de Cidades Inteligentes e Sustentáveis do PPGAU UNIVAG.
Site estático (HTML, CSS e JavaScript), pronto para o GitHub Pages.

## Páginas

| Arquivo | Seção | Abas |
|---|---|---|
| index.html | Página inicial | Busca integrada, mapa do Brasil, núcleos, mapa do portal, indicadores, novidades |
| observatorio.html | 01 O Observatório | Apresentação, Missão, Linhas de pesquisa, Equipe, Parceiros |
| cidades.html | 02 Cidades e Municípios | Perfis municipais, Mapas, Comparações |
| indicadores.html | 03 Indicadores Urbanos | Temas, Séries históricas, Painéis, Bases de dados |
| biblioteca.html | 04 Biblioteca Digital | Acervo com busca e filtros |
| politicas.html | 05 Políticas Públicas | Planos, Legislação, Programas, Instrumentos |
| boas-praticas.html | 06 Boas Práticas | Projetos, Experiências, Soluções urbanas |
| estudos.html | 07 Estudos e Publicações | Boletins, Diagnósticos, Relatórios técnicos |
| noticias.html | 08 Notícias e Participação | Notícias, Agenda, Envio de contribuições |
| municipio-*.html | Perfis municipais | Um por município |

Itens marcados como "Exemplo" são marcadores de lugar, a serem substituídos pelo conteúdo real.

## Publicar no GitHub Pages

Settings → Pages → Deploy from a branch → `main` / raiz.
